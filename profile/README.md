## Troubleshooting Common Issues

Install issues? Remove other antivirus products first, reboot, then run the Norton 360 installer as administrator.  
Performance problems? Exclude development and virtual machine folders from real-time scanning if builds slow down.  
License/activation? Sign in with the account that owns the subscription and refresh the licence from the app.  
Compatibility? Update to the current build when a Windows feature update leaves protection inactive.  
Update failures? Restart and use the built-in updater, since partial updates can leave services stopped.
